# 🚗 Vehicle Insurance Management System (VIMS) – DriveSecure

---

## 📌 Project Overview

DriveSecure is a web-based Vehicle Insurance Management System designed to simplify insurance policy administration and underwriter management. It provides separate Admin and Underwriter modules for managing accounts, creating policies, calculating premiums, and processing renewals.

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript** – Application logic and form validation
- **LocalStorage** – Client-side data persistence

---

## ✨ Key Features

### 👨‍💼 Admin Module
- Register and manage underwriter accounts.
- Search and view underwriter details.
- Manage account information and password recovery workflows.
- View dashboard statistics.

### 🚘 Underwriter Module
- Create and view vehicle insurance policies.
- Calculate premiums based on vehicle and insurance types.
- Update eligible insurance policies.
- Renew existing policies.
- View policy statistics and recent records.

### 🔐 Additional Features
- Client-side form validation.
- Interactive dashboards and reusable UI components.
- Separate interfaces for administrators and underwriters.
- Browser-based data storage.

## 📂 Project Structure

- `index.html` – Main application entry point
- `components/` – Reusable interface components
- `admin/` – Administrator functionality
- `underwriter/` – Insurance policy management
- `assests/` – CSS, JavaScript, and image assets

---

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Extract the project files.
3. Open the project folder in Visual Studio Code.
4. Launch `index.html` in a browser or use the Live Server extension.
5. Explore the Admin and Underwriter modules.
